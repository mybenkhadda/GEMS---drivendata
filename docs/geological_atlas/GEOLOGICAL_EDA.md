## Statistical rules
* Strikes: axial statistics on doubled angles (mean, resultant R, circular sd, Rayleigh test) - never arithmetic
  means of strike angles.
* Spatial dependence: distance bands and correlations use one random pixel per 1 km block; counts are blocks.
* Distance to mapped faults is descriptive context; it never selects features, thresholds or candidates.
* Feature classes (section 12) and lineament rules (section 13) are label-free and fixed in `config.DEFAULTS`.
* Fault-normal profiles: long (>= 5 km), linear (>= 0.9) training-visible traces, at most one per 3 x 3
  subregion; labelled descriptive examples, not validation.

## Feature classes (section 12)
spatially_limited (valid < 0.3), potentially_artifact (DEM seam / non-seam ratio > 1.5 or |rho| with distance to
the footprint edge > 0.5), noisy (lag-1 autocorrelation < 0.3), redundant (non-representative member of a
|rho| >= 0.9 cluster), informative_distinct. Retained = informative_distinct cluster representatives.

## Candidate lineaments (section 13)
Rules: combined evidence >= its 92nd percentile -> skeleton -> junctions removed -> segments >= 3 km with linearity
>= 0.85. Outputs: `04_eda/candidate_lineaments/candidate_lineaments.parquet` (GeoParquet, EPSG:32611),
`candidate_lineaments.geojson` (EPSG:4326), `candidate_lineaments_summary.csv`. Columns: candidate_id, geometry,
centroid_e / centroid_n, length_km, strike_deg, linearity, continuity, dominant_scale, magnetic / gravity /
terrain / dem _evidence, orientation_agreement, multiscale_persistence, coverage_quality, seam_proximity_m,
mapped_fault_distance_m (annotation only), evidence_count, interpretation, limitations,
status = `UNVERIFIED geological structure`.
