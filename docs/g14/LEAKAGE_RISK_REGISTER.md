# G14 leakage risk register

Severity: **High** = can inflate held-out DTI directly; **Medium** = can bias selection or inflate under some
configurations; **Low** = transductive or cosmetic, no label path. "Verify" = the check to run (all UNTESTED).

| # | risk | sev. | evidence | affected files | G14 fix | verify |
|---|---|---|---|---|---|---|
| 1 | Random patch sampling across folds | High | P7 / G07 handoffs drop "straddler" patches; a random patch can mix train and held-out labels | `g14/multiscale.py` | centres only where >= `min_train_frac` of the local window is in `unit.train`; loss mask = `unit.train`, so held-out labels never enter a loss | `test_targets_from_visible_labels_only`; audit `train_heldout_overlap == 0` |
| 2 | Spatially overlapping patches near boundaries | Medium | local windows can reach past the training mask | `g14/multiscale.py`, `g14/losses.py` | pixels outside the loss mask have weight 0 in every term | inspect `targets.loss_mask` in the preview cell |
| 3 | Nearby train / validation pixels | High | autocorrelation lengths reach 12.8 km (G13 EDA) | `g13/splits.py`, `g14/splits.py` | 13 km embargo buffer (G13 folds); `min_train_to_heldout_km` audited | `fold_audit.csv` |
| 4 | Fault segments crossing folds | Medium | G13 audit: 1 component crosses fold cv3 (split by the buffer) | `g14/splits.py` | buffer pixels never train; orientation-aware `fault_system_groups` + `system_crossing.csv` | `systems_in_both == 0` for disc units |
| 5 | Feature normalisation | Low | G13 store scales each feature over ALL valid pixels (label-free, transductive) | `g13/features.py`, `g14/contract.py` | stored channels keep a label-free affine pre-scale; the model sees per-unit stats fitted on `unit.train` only | `test_train_only_normalisation` |
| 6 | Geological clustering | Low | G13 regimes fitted on CV training pixels, label-free; unstable (ARI ≤ 0.52) | `g13/regimes.py`, `g14/splits.py`, `g14/ensemble.py` | regimes used only as label-free context / holdout groups; regime holdout reported separately | compare regime-holdout DTI with spatial CV |
| 7 | Orientation estimation from labels | Medium | orientation targets derive from mapped traces | `g14/multiscale.unit_targets` | computed from the unit's VISIBLE labels only | `test_targets_from_visible_labels_only` |
| 8 | Model selection optimism | Medium | many models chosen on the same 3 zones (G13 ablation: 25+ models) | `g14/evaluation.py` | nested (cross-fitted) operating points; report `optimism`; one locked-TEST look | `locked_test_log.jsonl` has one FIRST_LOOK |
| 9 | Threshold optimisation | High | thresholds tuned on the scored zone inflate DTI | `g14/evaluation.py` | (rep, area) for zone z chosen on the other zones of the task; never on TEST | `*_choice.csv` `dti_other` vs `dti_heldout` |
| 10 | Out-of-fold stacking | High | a blender trained on predictions of the zone it predicts | `g14/ensemble.py` | every learned weight / gate for zone z uses other zones' OOF maps only | `test_ensemble_weights_chosen_on_other_zones` |
| 11 | Cached label-distance rasters | Medium | a global distance-to-fault cache would encode held-out faults | `g14/multiscale.unit_targets`, `g14/contract.known_context` | computed per unit in memory from visible / permitted labels; never cached globally | code review: no label raster is written to the stack |
| 12 | Candidate recovery using held-out faults | High | recovery rules that look at "known" faults could see the held-out truth | `g14/graph.py` | graph uses only the unit's prediction, label-free evidence and (optional classifier) VISIBLE labels | `edge_labels_from_visible` docstring; audit |
| 13 | Regional / global context windows | Medium | windows of 51 / 205 km cover held-out geography | `g14/multiscale.py`, `g14/splits.py` | context inputs are label-free; known-context channels come from the permitted map; `strict_context_embargo` option drops centres whose regional window reaches the held-out zone | `train_px_with_context_reaching_heldout` in `fold_audit.csv`; ablation strict vs default |
| 14 | Known-fault context | High | known geometry is the strongest W2 feature; using all faults would leak the held-out truth | `g14/splits.py` | `permitted_known`: geo fold k -> faults outside fold k, its buffer and TEST; disc split d -> retained faults; final -> all faults (test-time input) | `assert_no_leakage`: no held-out truth in the known context |
| 15 | Pretraining / pseudo-labelling | High (future) | not implemented | — | any self-training must exclude held-out zones and TEST from pseudo-labels | add a test before enabling |
| 16 | Locked TEST reuse | High | repeated looks turn TEST into validation | `g14/evaluation.evaluate_locked_test` | refuses a second look unless forced; logged as `SECOND_LOOK` | `locked_test_log.jsonl` |
| 17 | Mixing split backends | High | Phase-5 units and G13 units differ; maps from one scored on the other | `g14/splits.py`, `g14/evaluation.py` | `load_g13_model` refuses the phase5 backend; unit maps of a wrong shape are refused; Phase-5 labels must equal G13 labels | constructor raises |
| 18 | Inner validation inside training geography | Low (optimism) | early stopping on autocorrelated pixels | `g14/train.py` | inner validation never touches the held-out zone; selection metric reported as "inner" only | history vs held-out DTI |
| 19 | Physically invalid augmentation | Low | TMI / mag_anom are asymmetric; flips create impossible anomalies | `g14/contract.py` | flip-unsafe bands excluded by default; contract check fails if included with D4 | `check_contract` row |
| 20 | Submission construction differs from evaluation | Medium | P6 audit: footprint-ranked full map != per-unit evaluated map | `g14/submission.py` | provenance must state construction + cross-fitted selection; the final unit's model is the one exported | provenance fields required |
