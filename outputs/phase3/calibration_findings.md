## Audit verdicts

**FAIL** (3)
- `C02` [calibration] Transform *family* differs by model type: rank_mean and B0 baselines were given RANK_TRANSFORM_GRID (floor 0.8-0.99, scale up to 2 -> top-q pixels saturate to exactly 1, a binary mask) while GBMs only got the probability grid (floor <= 0.4). The 0.1125 vs 0.0815 comparison confounds ensembling with transform family.
- `C04` [ensemble] Weighted ensemble map is built with weights selected on ALL folds (weights_all_folds); only its output transform is cross-fitted, so held-out labels choose the weights of the reported 0.0815.
- `C14` [discovery] Pseudo-discovery recall@tol and extra_confident_km2 use threshold 0.5 on transformed maps whose scales differ per model (G1 is >= 0.5 over most of the evaluation zone): high G1 recall is an area effect, not localisation. Replaced by matched-area budgets (budget.py, discovery3.py).

**WARN** (16)
- `C03` [calibration] Probability-grid optimum for G3 sits on the grid edge (scale=3 max, floor=0.4 max): single-model DTI is truncated by the search grid.
- `C05` [ensemble] Ensemble weights are optimised on raw member maps but the ensemble is scored after a transform: inconsistent objectives (weights=1.0 on G3 reproduces G3 exactly).
- `C06` [ensemble] Member set (top-3 by pooled DTI) and ensemble kind (mean / rank / weighted) are selected on the same folds that report the score: max-of-several selection optimism, not nested.
- `C08` [ranking] Ordinal ranks break ties by raster order (north to south): a threshold falling inside a tied plateau keeps its northern part. Material only if large tie blocks exist (see data check D03).
- `C09` [ranking] Ranks are global over the stitched OOF map, a mixture of three fold models with different score scales: label-free (no leakage) but the area each fold receives under a global cut depends on its model's scale.
- `C11` [masks] Pseudo-discovery reported 'excl' (retained faults dilated 300 m excluded) and 'no_exclusion' (retained faults counted as TRUTH). The hidden-test analogue when known faults are not excluded — withheld faults are truth and predictions on retained faults count as FP — was missing. Added in discovery3.
- `C12` [submission] Submission maps are fold-model AVERAGES predicting everywhere, including each model's own training area, while OOF maps are stitched single-model predictions. The output transform tuned on OOF scale is applied to a different score distribution, and mapped faults get in-sample scores (see data check D06).

## Reading rules

- If `hard_threshold` >= every soft family for single models, the DTI-optimal output is binary (as the vertex argument in curves.py predicts) and probability calibration should not be tuned further.
- If `rank_power_p2` on a single model (e.g. G3) is within 0.01 of the Phase-2 rank ensemble 0.1125, the Phase-2 ensemble gain was a transform-family artifact (C02), not ensembling.
- `isotonic` (calibrated probabilities) is expected to score far below threshold families: calibration and DTI optimality are different goals.
- `optimism` = in-sample minus cross-fitted DTI; > 0.01 means the family over-fits its own grid.
